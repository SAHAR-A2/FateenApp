| ----- | ------------ |

### 2.4 Immutability audit (history)

- 11 history tables are **INSERT-only**, enforced by `prevent_history_mutation()`
  triggers (11) — UPDATE/DELETE raise at the storage layer.
- `UNIQUE (original_entity_id, version_number)` on all 11.
- `previous_version_id` self-chains with RESTRICT.
- `version_status` ENUM (`draft → pending_approval → approved → superseded`) +
  `superseded_at` model version lifecycle; `snapshot_hash`/`checksum` for tamper
  evidence.
- No `updated_at`/`deleted_at` on history rows (immutability by design).

### 2.5 Trigger coverage

- Every table with `updated_at` has a `set_updated_at()` trigger (53).
- Every history table has a `prevent_history_mutation()` trigger (11).
- Search tables have **zero** triggers (no synchronization — Mission 08 rule).
- Trigger count: **64**.

### 2.6 Index coverage

- Total index statements: **206**.
