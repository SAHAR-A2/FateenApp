# إضافة خط Cairo — خطوات مضمونة بدون أي خطأ

هذا الدليل يشرح كيف تحمّل خط Cairo (نفس الخط المستخدم في تصاميم الفيجما) وتضيفه
للتطبيق بأمان تام. اتبع الخطوات بالترتيب بدون تخطي أي خطوة.

## لماذا ما حملته لك مباشرة؟

حاولت تحميله تلقائياً، لكن GitHub يمنع الأدوات الآلية من تحميل الملفات الثنائية
(zip/ttf) مباشرة، وملفات الخطوط لازم تكون سليمة 100% وإلا التطبيق ما يبني
(build error). عشان "بدون ولا غلطة" زي ما طلبت، الأضمن إنك تحمّلها بنفسك من
المصدر الرسمي (دقيقتين بس) وأنا جهزت كل شي عشان تركيبها يكون تلقائي 100%.

## الخطوات

### 1. حمّل ملفات الخط
اذهب إلى الرابط الرسمي من Google Fonts:

👉 https://fonts.google.com/specimen/Cairo

اضغط زر **Download family** (أعلى يمين الصفحة). بينزل ملف `Cairo.zip`.

### 2. فك الضغط واختر 5 ملفات فقط
داخل الـ zip بتلقى مجلد `static/` فيه أوزان كثيرة. اختر هذي الملفات بالضبط:

- `Cairo-Regular.ttf`
- `Cairo-Medium.ttf`
- `Cairo-SemiBold.ttf`
- `Cairo-Bold.ttf`
- `Cairo-ExtraBold.ttf`

### 3. انسخها إلى مجلد المشروع
انسخ الملفات الخمسة إلى هذا المسار بالضبط داخل مشروعك:

```
fateen_app/assets/fonts/
```

(المجلد موجود مسبقاً وفاضي — بس حط الملفات فيه، لا تغيّر أسماء الملفات)

### 4. فعّل الخط في pubspec.yaml
افتح `pubspec.yaml`، وبتلقى بالأسفل قسم معلّق (commented) بعلامة `#` اسمه
"CAIRO FONT". احذف علامة `#` من بداية كل سطر داخل قسم `fonts:` فقط (اترك بقية
الملف كما هو). يعني يتحول من:

```yaml
  # fonts:
  #   - family: Cairo
  #     fonts:
  #       - asset: assets/fonts/Cairo-Regular.ttf
```

إلى:

```yaml
  fonts:
    - family: Cairo
      fonts:
        - asset: assets/fonts/Cairo-Regular.ttf
```

⚠️ **مهم**: احترم المسافات (indentation) بالضبط زي ما هي — YAML حساس جداً
للمسافات. الأسهل إنك تنسخ القسم كامل بعد حذف الـ `#` فقط بدون تغيير أي مسافة.

### 5. شغّل الأوامر
```
flutter clean
flutter pub get
flutter run
```

خلاص — التطبيق كامل بيتحول لخط Cairo تلقائياً، بدون ما تلمس أي شاشة أو ملف
Dart ثاني. هذا لأن `lib/core/theme/app_fonts.dart` مسبقاً معرّف `family = 'Cairo'`
و `app_theme.dart` يطبقه على كل التطبيق من مكان واحد.

## لو صار خطأ

- **"Unable to find directory entry"**: تأكد إن أسماء الملفات في `assets/fonts/`
  مطابقة تماماً لأسماء الملفات في `pubspec.yaml` (حساس لحالة الأحرف).
- **الخط ما تغيّر بعد `flutter run`**: جرب `flutter clean` ثم `flutter pub get`
  مرة ثانية — أحياناً الكاش القديم يعلق.
- **أي خطأ ثاني**: ارجع الخطوة 4 وتأكد المسافات (spaces) صح، هذا 90% من أخطاء YAML.

## ملاحظة

إذا ما ضفت الخط أبداً، التطبيق **ما راح يتعطل** — بيستمر يشتغل بخط النظام
الافتراضي بشكل طبيعي (شفناها في app_fonts.dart، مصممة كذا خصيصاً عشان ما
يصير ولا خطأ بأي احتمال).
